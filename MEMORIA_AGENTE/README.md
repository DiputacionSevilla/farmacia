# Memoria del agente programador

Esta carpeta es un volcado de la memoria persistente que Claude Code
(agente IA usado para el desarrollo de esta aplicación) mantuvo durante
las sesiones de trabajo, para que el contexto no se pierda si el
desarrollo se retoma desde otro equipo.

No forma parte de la aplicación ni se despliega con ella — es
documentación de proceso, complementaria al
[`../SDD_PWA_Farmacias_Guardia_Mairena.md`](../SDD_PWA_Farmacias_Guardia_Mairena.md)
y al
[`../ANEXO_SDD_Descubrimiento_PDF_OCR_Farmacias_Mairena.md`](../ANEXO_SDD_Descubrimiento_PDF_OCR_Farmacias_Mairena.md).

Empezar por [`MEMORY.md`](MEMORY.md), el índice.

Si se retoma el desarrollo con Claude Code desde otro equipo, estos
ficheros pueden copiarse de vuelta al directorio de memoria del proyecto
en ese equipo (`~/.claude/projects/<id-del-proyecto>/memory/`) para que
el agente recupere el contexto automáticamente al empezar.
